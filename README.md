# 🎨 Drawing Palette

> A simple drawing application made with Python and Tkinter.

## About

Drawing Palette is a small project that combines my interest in drawing with Python.

It has a blank canvas where I can draw using my mouse, change the brush size, choose different colors, use an eraser, and clear the canvas.

## Features

- Different color options
- Custom color picker
- Adjustable brush size
- Eraser
- Clear canvas
- Mouse-based drawing
- Simple graphical interface

## Built With

- Python
- Tkinter

No external libraries are required.

## How to Run

Make sure Python is installed.

Run:

    python drawing_palette.py
